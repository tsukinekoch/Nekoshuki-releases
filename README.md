# 猫手記
月猫が個人的に欲しかった機能を詰め込んだｲｶﾚﾎﾟﾝﾁテキストエディタです。  
空白txtファイルを１つ開いた状態でだいたい２１０MBくらいメモリを消費します。  
碌な最適化もされてないソフトですが、興味がある方はぜひ使ってみてください。  
[releasesから最新版をダウンロード](https://github.com/tsukinekoch/Nekoshuki-releases/releases)。
